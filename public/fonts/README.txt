فونت‌ها
=======
فونت‌های «B Nazanin» (متن) و «B Titr» (تیترها) فونت‌های تجاری هستند و داخل پروژه قرار داده نشده‌اند.
دو راه برای استفاده:

۱) نصب روی همان کامپیوتری که مرورگر روی آن باز می‌شود  → خودکار استفاده می‌شوند.
۲) فایل‌های دارای مجوز را اینجا بگذارید تا برای همهٔ کاربران بارگذاری شوند:
     BNazanin.woff2  (یا BNazanin.ttf)
     BTitr.woff2     (یا BTitr.ttf)

اگر هیچ‌کدام در دسترس نباشد، به‌صورت خودکار از وزیرمتن/Tahoma استفاده می‌شود.

انتخاب فونت (نسخه ۶)
====================
از «تم و رنگ‌ها» ← بخش «فونت» می‌توانید فونت فارسی، انگلیسی، تیترها و اندازهٔ متن را برای کل سایت انتخاب کنید.
برای اینکه فونتِ انتخابی روی همهٔ دستگاه‌ها بیاید، فایلش را با این نام‌ها اینجا بگذارید:
  Vazirmatn.woff2  IRANSans.woff2  Shabnam.woff2  Sahel.woff2  Samim.woff2  Yekan.woff2  BMitra.woff2  Inter.woff2  Roboto.woff2
یا از همان پنل «افزودن فونت از فایل» را بزنید (فقط برای همان مرورگر ذخیره می‌شود).
