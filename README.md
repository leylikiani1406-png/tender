# سامانه مدیریت مناقصات — کوشا معدن

## تغییرات نسخه ۶
- **داشبورد:** چهار کارت کنار هم در بالای صفحه (اتمام‌یافته، در حال انجام، استعلام قیمت، پروپوزال)، هر کدام با «کشوی سال». با کلیک روی هر کارت، نمودارهای گرافیکی (حلقه‌ای، ستونی، ناحیه‌ای، شعاعی، گل‌سرخی، افقی) و یک دیتاتیبل (جستجو، مرتب‌سازی، خروجی اکسل) پایین صفحه نمایش داده می‌شود.
  - در حال انجام: تعداد به تفکیک ماه و وضعیت (منتظر ارسال / ارسال‌شده / منتظر پاسخ)، مبلغ پیشنهادی و ضمانت‌نامه، مهلت‌ها، ریسک و فرصت. ضریب موفقیت برای این بخش محاسبه نمی‌شود.
  - اتمام‌یافته، استعلام و پروپوزال: ضریب موفقیت. استعلام: «انتخاب‌شده» = برنده، «بسته‌شده» = بازنده، «باز/پاسخ داده شد» = در انتظار پاسخ.
- **کارتابل مدیریت مناقصات:** کشوی تحلیل تصمیم شرکت / عدم شرکت و ریسک و فرصت بالای جدول.
- **رزومه‌ساز:** قالب «رسمی جدولی» + قالب اکسل رزومه (هر بخش یک شیت، هر ستون یک فیلد، هر سطر یک مورد).
- **فونت:** «تم و رنگ‌ها» ← فونت فارسی، انگلیسی، تیترها و اندازهٔ متن برای کل سایت؛ امکان افزودن فایل فونت (راهنما: public/fonts/README.txt).
- **کاربران:** دکمهٔ «حذف». کاربری که سابقه دارد (مناقصه، کامنت و …) به‌جای حذف، غیرفعال می‌شود؛ حساب admin، حساب خودتان و آخرین مدیر ارشد قابل حذف نیستند.
- تغییر دیتابیس ندارد؛ فایل‌ها را جایگزین کنید و دوباره `npm start` بزنید.

## تغییرات نسخه ۵

**مناقصات معدنی**
- **داشبورد:** انتخاب بخش (مناقصه‌های اتمام‌یافته / در حال انجام / استعلام‌ها / پروپوزال‌ها) و سال شمسی؛ نمودارها بر اساس همان بخش عوض می‌شود. اتمام‌یافته: ضریب موفقیت هر سال، فهرست برنده‌ها با امتیاز کیفی/فنی/مالی/کل، رتبه، قیمت پیشنهادی و مبلغ قرارداد، کارفرماهایی که بیشتر/کمتر برنده شده‌ایم. در حال انجام: تعداد و مبلغ هر مرحله، ضمانت‌نامه‌ها، مهلت‌های نزدیک. پایین هر صفحه: تصمیم شرکت/عدم شرکت و **ریسک و فرصت** (اختیاری).
- **کارتابل:** ستون «تاریخ دریافت»؛ شمارندهٔ قرمز گرد کنار منو (با انجام کار کم می‌شود)؛ برچسب «اعلان تغییر».
- **کامنت و تاریخچه** و **اعلان تغییرات** (با پیوست و اعمال اختیاری مقدار جدید روی مناقصه) در صفحهٔ هر مناقصه؛ اعلان‌ها در زنگ 🔔 می‌آید.
- **مدیر دفتر فنی** علاوه بر روش و زمان‌بندی، «قیمت پیشنهادی» را هم ثبت می‌کند.
- **اتمام‌یافته:** پوشه‌های سال؛ «افزودن مناقصهٔ سال‌های قبل» به‌صورت دستی، گروهی از اکسل، یا خواندن از فایل Word/PDF (+ بارگذاری مدارک). داشبورد از همین داده‌ها می‌خواند.
- **استعلام قیمت:** پوشه‌های تو در توی دلخواه، ردیف استعلام و پیوست.
- **انصراف از مناقصه:** عنوان، کارفرما، تاریخ، دلیل و نامه‌ها؛ قابل انتخاب بر اساس سال.
- **رزومه‌ساز:** دکمهٔ «ورود از فایل» (Excel / CSV / Word docx / PDF متنی) و جایگذاری در قالب انتخابی.

**مناقصات عمومی (نفت و گاز) — گردش‌کار با دروازه‌های تصمیم**
ثبت (کارشناس مناقصات) ← بررسی فنی و انطباق با استانداردها، روش/زمان‌بندی/قیمت (مدیر دفتر فنی) ← تصمیم Go / No-Go (مدیرعامل؛ با گزینهٔ «نیاز به ضمانت‌نامه») ← ضمانت‌نامهٔ شرکت در مناقصه (مدیر مالی) ← ارجاع تهیهٔ مدارک + چک‌لیست بستهٔ پیشنهاد (PQ، پیشنهاد فنی/بازرگانی جدا، HSE، QA/QC، IVC، Deviation List، Bid Bond …) ← ارسال ← نتیجه. کارتابل نفت و گاز، کامنت/تاریخچه و اعلان تغییرات هم دارد.

**انگلیسی:** با انتخاب English همهٔ متن‌های رابط (منو، دکمه، جدول، پیام‌ها) ترجمه می‌شود؛ داده‌های واردشده (عنوان مناقصه، کارفرما …) دست‌نخورده می‌مانند. عبارت جدید را در `public/js/i18n-en.js` اضافه کنید.

**رمز عبور:** چشمِ خط‌خورده = رمز پنهان؛ چشمِ باز = رمز آشکار.

**اجرا روی دیتابیس موجود:** `npm install` و سپس `npm run migrate` (مهاجرت `v7_workflow.sql` تکرارپذیر است). وابستگی‌های تازه: `pdf-parse` و `mammoth`.


Node.js + Express + PostgreSQL | فرانت‌اند Vanilla JS | فارسی/انگلیسی

## راه‌اندازی روی کامپیوتر خودتان
1. Node.js نسخه ۱۸ یا بالاتر نصب باشد (`node -v`).
2. در پوشه‌ی پروژه (پاورشل):
   ```
   npm install
   copy .env.example .env
   ```
3. فایل `.env` را باز کنید و `JWT_SECRET` (یک رشته‌ی تصادفی بلند) و مشخصات دیتابیس را پر کنید.
4. ساخت جدول‌ها (فقط یک بار):
   ```
   npm run setup-db
   ```
   رمز موقت کاربر `admin` در خروجی چاپ می‌شود. ⚠️ اگر جدول‌ها از قبل باشند، این دستور چیزی را پاک نمی‌کند؛ برای پاک‌کردن و ساخت مجدد: `npm run setup-db -- --force`
5. اجرا: `npm start` ← مرورگر: http://localhost:3000
6. لوگو: فایل لوگو را با نام `logo.png` در `public/images/` بگذارید.

## ارتقا از نسخه قبل به نسخه ۳ (بدون پاک شدن داده‌ها)
1. فایل‌های جدید را روی پروژه کپی کنید و `npm install` بزنید (کتابخانه `xlsx` برای خواندن اکسل اضافه شده).
2. **یک بار** مهاجرت را اجرا کنید: `npm run migrate` (با `.env` متصل به دیتابیس رانفلر). چندبار اجرا شود مشکلی ندارد و اگر خطا بدهد هیچ تغییری اعمال نمی‌شود. قبلش از دیتابیس پشتیبان بگیرید.
3. مناقصه‌های قبلی همگی نوع «اکتشافی» می‌گیرند؛ نوع را از «ویرایش مشخصات» هر مناقصه عوض کنید. وضعیت‌های قبلی به این صورت تبدیل می‌شوند: اعلام/بررسی فنی/پیشنهاد مالی/تأیید مدیرعامل ← در انتظار تصمیم؛ ارسال‌شده ← در حال انجام؛ برنده/بازنده ← اتمام‌یافته (با همان نتیجه)؛ لغو شده ← بسته شد.
4. اسناد کیفی و پروپوزال‌های قبلی به بخش جدید پوشه‌ها (در ریشه) منتقل می‌شوند. فرم‌های ایزو و کارکنان کلیدی بدون تغییر در «سایر آرشیو» هستند.
نصب تازه: `npm run setup-db` همه چیز را (با نسخه ۳) می‌سازد.

## نقش‌ها و گردش‌کار مناقصه (نسخه ۳)
1. **کارشناس مناقصات** مناقصه را (اکتشافی یا نظارتی) ثبت و اسناد دانلودشده از سایت هزاره را بارگذاری می‌کند. مناقصه همزمان به کارتابل **مدیر دفتر فنی** و **مدیرعامل** می‌رود.
2. **مدیر دفتر فنی** نام فرد ارجاع‌شده، روش انجام و برنامه زمانبندی را ثبت می‌کند. فقط نام فرد در کادر «ارجاع شده به» برای کارشناس نمایش داده می‌شود.
3. **مدیرعامل** «بله» یا «خیر» می‌زند. اگر ضمانت‌نامه لازم باشد گزینه آن را می‌زند تا به کارتابل **مالی** برود.
   - خیر ← وضعیت «مناقصه بسته شد» و ورود به کارتابل کارشناس.
   - بله ← «در حال انجام» و ورود به کارتابل کارشناس.
4. **مالی** ضمانت‌نامه را (توضیح و فایل) ثبت می‌کند و «دریافت شد» می‌زند؛ به کارتابل کارشناس خبر می‌رسد.
5. کارشناس پس از انجام کارها «اتمام مناقصه» را می‌زند؛ مناقصه به «اتمام‌یافته» می‌رود و فرم نتیجه پر می‌شود.
هر مناقصه سه فرم دارد: Document Feasibility، Tender Checklist (بر اساس جدول‌های ارزیابی کیفی و فنی اسناد) و Result Form. مدیر ارشد به همه‌چیز دسترسی دارد.

## داشبورد و اکسل
داشبورد خالی است تا فایل اکسل نتایج بارگذاری شود (مدیرعامل، کارشناس مناقصات یا مدیر ارشد). ستون‌ها: **سال** (مثلاً ۱۴۰۴)، **عنوان** (اختیاری)، **نوع** (مناقصه یا پروپوزال)، **نتیجه** (برنده یا بازنده)، **مبلغ قرارداد**. دکمه «دریافت اکسل نمونه» همین ستون‌ها را می‌دهد. با هر بارگذاری جدید، آمار قبلی جایگزین می‌شود.

## استقرار روی رانفلر
- متغیرهای `.env` را در بخش Environment Variables سرویس وارد کنید (فایل `.env` را آپلود نکنید).
- Build: `npm install` — Start: `npm start` — پورت از متغیر `PORT` خوانده می‌شود.
- جدول‌ها را از کامپیوتر خودتان بسازید: `.env` محلی را به دیتابیس رانفلر وصل کنید و `npm run setup-db` بزنید.
- ⚠️ فایل‌های آپلودشده در پوشه‌ی `uploads/` ذخیره می‌شوند. اگر دیسک سرویس دائمی (Persistent Volume) نباشد، با هر دیپلوی پاک می‌شوند. مسیر دیسک دائمی را در `UPLOAD_DIR` بگذارید.
- برای HTTPS و دامنه از تنظیمات رانفلر استفاده کنید.

## امنیت
- `.env` و رمزها را هرگز در چت/گیت قرار ندهید.
- بعد از اولین ورود رمز `admin` اجباراً عوض می‌شود.
- پشتیبان‌گیری منظم از دیتابیس و پوشه‌ی `uploads` بگیرید.

## وضعیت نسخه ۴ (نهایی)
- **مناقصات معدنی**: کارتابل، مناقصات در حال انجام/اتمام‌یافته، فرم‌های سه‌گانه، پیشنهادها، کاربران (و ورود از اکسل)، ارجاع کار، آرشیو مدارک و خروجی PDF، تم و فونت.
- **رزومه‌ساز**: ۴ قالب، تم رنگی (پیش‌فرض قرمز و سفید با لوگو)، دو زبان فارسی/انگلیسی، ترجمهٔ خودکار، ذخیرهٔ خودکار و خروجی PDF (چاپ مرورگر).
- **مناقصات عمومی (نفت و گاز)**:
  - داشبورد: شاخص‌ها (خط لوله، ارزش وزنی، نرخ برد، شکاف استاندارد)، قیف مراحل، نمودار حوزه‌ها، مهلت‌ها در هر ماه و هشدار مهلت‌های نزدیک.
  - فهرست: جدول و تابلو، جستجو و فیلتر (وضعیت، مرحله، حوزه، بازهٔ مهلت)، مرتب‌سازی، خروجی اکسل.
  - صفحهٔ هر مناقصه: خلاصه و پیوست، تصمیم شرکت/عدم شرکت با ۶ معیار و امتیاز کل، استانداردها با نوار انطباق، ماتریس ریسک، مقایسهٔ قیمت رقبا و فهرست کارها.
  - استانداردها: ۴۰ استاندارد اولیه (API، ASME، ISO، NORSOK، IEC، NACE، DNV، IPS) با جستجو و افزودن/حذف.
- مبالغ داشبورد عمومی بدون تبدیل ارز جمع می‌شوند.
- فونت‌های B Nazanin و B Titr مجوزی هستند و داخل پروژه نیستند؛ فایل‌ها را در `public/fonts` بگذارید (راهنما: `public/fonts/README.txt`).
- ترجمه: با `TRANSLATE_URL` و `TRANSLATE_API_KEY` در `.env` از سرویس شما استفاده می‌شود؛ بدون آن ابتدا MyMemory و در صورت نبود اینترنت واژه‌نامهٔ داخلی. ترجمهٔ ماشینی (بخصوص نام افراد و شرکت‌ها) همیشه باید بازبینی شود.
- پس از `npm install`: ارتقا `npm run migrate`، نصب تازه `npm run setup-db`، اجرا `npm start`.
